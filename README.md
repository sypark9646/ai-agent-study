# ai-agent-study
각 주차는 개념 학습 → 실습 단계 → 심화 프로젝트 단계로 진행하며, 매주 구현물과 함께 컨설팅 장표(산출물)를 작성한다.

| Week | 주제 | Hands-on | 컨설팅 장표 | 권장 형식 |
|------|------|----------|------------|-----------|
| 1 | Enterprise Agent Architecture | Single Agent 구현 | Architecture Diagram | PPT, draw.io, Git |
| 2 | Prompt & Context Engineering | Context 최적화 | Context Flow Diagram | PPT, draw.io, Excel |
| 3 | MCP Engineering | MCP Server 직접 구현 | MCP Sequence Diagram | PPT, draw.io, Excel, JSON, Git |
| 4 | Skill Engineering | Skill 설계 및 재사용 구조 | Skill Dependency Diagram | PPT, draw.io, Excel, Markdown |
| 5 | Harness Engineering **(+ Test Harness & 테스트 자동화)** | Retry·Logging·Validation + 테스트 하네스 구현 | Request Lifecycle Diagram, Test Strategy | PPT, draw.io, Excel, JSON, Git, CI |
| 6 | Inner Loop & Planning | Reflection, Planning Agent | Agent Workflow Diagram | PPT, draw.io, Excel, JSON |
| 7 | Enterprise Architecture & 운영 | 인증, 권한, Session, Redis, Audit | 전체 시스템 아키텍처 | PPT, draw.io, Excel |
| 8 | Production Review | 고객사 발표 수준 리뷰 | 고객사 제안서 수준 발표 | PPT, draw.io, Excel, Git |

## 매주 병행하는 컨설팅 산출물(장표) 요약

매주 구현만 하지 말고 컨설팅 산출물 작성을 병행한다. 단순히 코드를 작성하는 데 그치지 않고, 컨설팅 프로젝트에서 실제로 필요한 설계 문서와 발표 자료까지 함께 준비하는 연습이 된다.

| 4 | Skill | Skill Dependency Diagram |
